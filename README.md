# Kopi

Copy on one machine, paste on another. Kopi keeps plain-text clipboards in sync across your
Windows and macOS devices on the same network, encrypted with a shared passphrase.

Personal project, work in progress. See [SPEC.md](SPEC.md) for behavior and
[PLAN.md](PLAN.md) for the build plan.
